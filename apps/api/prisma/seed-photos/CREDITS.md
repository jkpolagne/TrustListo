licenses below. They are **illustrative only**: they do not show the actual units in the seed
data, and the seed's project and model names are fictional pairings.

Each file was resized to 1280px wide and converted to WebP (a modification). Under the
Share-Alike licenses, these modified versions are shared under the same license as the
